# Completeness — Connected agents

## Covered

- Public-to-login device-code return.
- Desktop and mobile immutable device review.
- Typed approve and deny controls.
- Installation list and detail.
- Typed grant and installation revocation.
- Safe audit and receipt-reference presentation.
- First-touch, disclaimer, vocabulary, accessibility, network, and overflow gates.

## Deferred by phase boundary

- Phase 5: access and refresh credential issuance, refresh recovery, and
  revoked-token rejection.
- Later paid phases: populated payment receipt and task evidence.
- Production Spark browser pass occurs only after authorized deployment.

## Human demo

1. Start a connection on Apple Assistant and open the complete verification URI.
2. Sign in and narrate each immutable review field.
3. Show that ordinary text and a near-match cannot enable approval.
4. Type `APPROVE`, then open Settings → Connected Agents.
5. Inspect scopes, audit, and receipt references.
6. Type `REVOKE GRANT`, reload, then type `REVOKE AGENT`.
7. Repeat with a second code and type `DENY`.
